# 🎬 CineSocial — Social Platform for Cinephiles

🔗 RENDER - https://cinesocial-app.onrender.com/
🔗 VERCEL = https://cinesocial-webapp.vercel.app/

## 🚀 Overview

**CineSocial** is a modern social platform designed exclusively for **cinephiles and cinema enthusiasts**. It combines the real-time, expressive nature of microblogging with the depth of community-driven discussions.

The platform enables users to **share opinions, explore movies, engage in discussions, and discover content tailored to their cinematic taste** — all in one place.

---

## ✨ Core Features

### 1. 🎭 Social Posting System

Users can create and interact with multiple types of cinema-related content:

* 📝 Stories / short opinions (like tweets)
* 📊 Polls (e.g., “Best Nolan movie?”)
* 🤔 “What If” scenarios (alternate plot ideas)
* 🖼️ Image posts with captions (movie stills, posters, memes)

**Engagement Features:**

* Like, comment, share
* Threaded discussions
* Real-time feed updates

---

### 2. 🏘️ Community System

Users can create and join niche communities based on their interests.

**Examples:**

* Nolan Fans Club
* Marvel Universe
* Bollywood Classics
* Anime Movie Lovers

**Community Features:**

* Dedicated discussion feed
* Group chats (real-time)
* Admin/moderation controls
* Member-based interactions

---

### 3. 🤖 AI Movie Recommendation System

An intelligent chatbot that suggests movies based on:

* User mood (e.g., “sad”, “thriller mood”)
* Genre preferences
* Past activity

**Capabilities:**

* Conversational UI
* Personalized recommendations
* Context-aware suggestions

---

### 4. 📊 User Profile

Each user gets a personalized dashboard to track activity and preferences.

**Includes:**

* Total posts
* Followers & following count
* Engagement metrics
* 🎬 Movie wishlist (saved movies to watch later)

---

## 🧱 Tech Stack

### Frontend

* React.js
* Tailwind CSS
* Modern UI/UX principles
* Responsive design

### Backend

* Node.js
* Express.js

### Database

* MongoDB (NoSQL, scalable for social data)

* Cloudinary (media storage)

* Redis (caching)
